# 人物身体动画使用说明

2026-10-19 · Unity 2022.3.62f1c1 验证。

叶瞬光 16 段、星见雅 32 段，每段提供 InPlace / RootMotion 两版，共 96 个 Humanoid 动画，另附两个专用 Avatar。文件为可编辑的原生 `.anim`，动画合计约 343 MB。这里只交付动画资源，没有建立状态机或 Animator Controller。

## 先选对 Avatar

在角色模型自身的 Animator 组件中，将 Avatar 指定为同目录的 `Yeshunguang_TargetAvatar.asset` 或 `Miyabi_TargetAvatar.asset`。

这些 Avatar 针对本仓库 MMD 导出的骨架修正了手指、袖子与头部的自动映射。不要继续使用模型原来自动生成的 Avatar 来判断动作是否正确。主模型的导入设置、场景和 Animator 组件均未代为修改；你可以在接入动画时自行指定。

已验证的模型：

- 叶瞬光：`Assets/Model/Player/yeshunguang/叶瞬光.fbx`。
- 星见雅：仓库根目录 `ModelExports/Unity/星见雅/星见雅.fbx`。该模型尚未搬进 ZERO；使用前将模型与其贴图一起导入，再指定这里的 Miyabi Avatar。本次在独立工程验证了该 FBX 的默认 Humanoid 导入与专用 Avatar 配合使用。

## 两种版本

| 文件夹 | 使用方式 |
| --- | --- |
| InPlace | 原地身体动作。Animator 关闭 Apply Root Motion，由你的人物移动逻辑控制位移。水平身体起点已归零，保留动作自身的上下起伏与转身。适合先搭状态机。 |
| RootMotion | 保留源动画的根位移和旋转。需要根运动时开启 Apply Root Motion，并自行与移动、碰撞逻辑配合。源动画的冲刺/闪避可能位移很大，不能直接等同于最终玩法速度。 |

只选一套接入即可，不必把两套都放进 Controller。两版采用同一套专用 Avatar。

## 名称与时间

- `Run_Loop` 是已开启循环的跑步片段；`Run_End` 是停跑后摇。
- `Attack_01` 等按源文件名整理，`_End` 为对应结束资源，`_02` 为分支。具体连击顺序、可取消帧、命中帧由你预览后决定；没有写入 Animation Event。
- 星见雅额外保留 `Attack_06` 和 `_02` 等源资源分支，编号不代表已经确认的基础普攻段数。
- 闪避和收招资源常附带回到待机的尾段，完整时长较长；不需要等整段播完再切换。清单中的时长为完整资源时长。
- 待机循环已启用 Loop Time；`Idle_AFK` 保持单次播放。
- 完整动作清单见下表和 `AnimationCatalog.csv`。每个名字在 InPlace / RootMotion 各有一份。

## 适配范围与验证

这套资源适配身体与手指。武器、刀鞘、特效及游戏专用附属骨骼轨道未移植，预览中的武器也不代表已完成挂点适配。头发、衣服仍依赖现有的骨骼权重与后续物理设置；主工程原有 SpringBone 配置未改动。

96/96 个片段已在独立工程重新导入、连续播放并检查数值，原地版没有根物体平移。曲线精简后的姿势与修正前参考逐帧对比，最大骨骼位置差约 2.3 mm、最大旋转差约 0.25°。两份专用 Avatar 已与现有模型原导入设置的副本逐一验证。叶瞬光停跑的原地漂移已修复，水平髋部变化约 0.16 m，为身体摆动。

这不等于已经验证你之后的动作混合、状态切换、武器挂点或碰撞控制。最终报告与每段四帧预览在项目根目录 `AnimationReview/`，预览使用纯色材质和静态附属骨骼，不是最终渲染效果。
